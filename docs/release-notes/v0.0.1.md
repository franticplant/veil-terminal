First build of Veil Terminal: an SSH terminal for Android built around compartments, with a Rust
engine and a disposable UI, on its way to an engine inside a Microdroid VM. This is an early
pre-release for testing. Expect rough edges and changes that break things.

**What's in it**

- **SSH.**
  - Post-quantum hybrid key exchange (`mlkem768x25519-sha256`), required by default; classical key
    exchange only for hosts you allow.
  - Host keys are verified and remembered.
  - Password and keyboard-interactive login.
  - Keys generated in Android Keystore, in StrongBox where the phone has it. They can be limited to
    use while the phone is unlocked, and private keys never leave the hardware. The engine never
    holds a key: it asks the app to sign a login, and the app checks that the request really is one.
  - Saved connection profiles; reconnect.
- **Terminal.**
  - alacritty_terminal emulation; touch, mouse and hardware keyboard input; pinch to resize.
  - Themes, AMOLED black among them.
  - Fullscreen, optionally covering the display cutout; all four orientations.
  - OSC 52 clipboard with an ask/allow/deny policy.
- **The engine runs as a native process of its own** (no JVM, about 6 MB). It is the same binary
  the Microdroid payload will run.

**Verify the download**

```sh
gh attestation verify veil-0.0.1.apk -R franticplant/veil-terminal
sha256sum -c SHA256SUMS
```
