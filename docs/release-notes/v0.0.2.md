Licensing and packaging release. The app itself is the same as v0.0.1.

**What's new**

- **Third-party licenses.** Every APK now carries the notices of all the Java, Kotlin and Rust
  components it ships, with their license texts. Find them under Settings → Open-source licenses
  (in devd, at the bottom of the Status tab). Each release also attaches them as files of their own.
  v0.0.1 shipped without them.
- **Every target in the release:**
  - Veil, as before;
  - Veil dev, with the development control plane;
  - devd, the development agent;
  - veil-ctl, devd's laptop CLI: a static binary that runs on any x86_64 Linux.

  The table below says which file is for whom. If you only want the terminal, install
  `veil-0.0.2.apk`.
- **Build pipeline.** Releases are built on CI from one pinned toolchain list, without a build
  container. Downloads are checked by SHA-256, and every file is attested (build provenance and
  SBOM).
