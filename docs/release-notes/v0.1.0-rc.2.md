# Veil Terminal v0.1.0-rc.2

Refresh of the first protected-VM release candidate.

This build keeps the VM-first layout from `v0.1.0-rc.1` and adds the terminal
font fix plus the updated documentation.

## What changed

- **Bundled Hack Nerd Font Mono.** Shell prompts, tmux, editors and other
  programs that use Nerd Font glyphs no longer depend on a patched system
  font being installed on the phone. The font is packaged in the APK and its
  license is included in the third-party notices.
- **Documentation refresh.** The README now opens with the point of Veil, a
  Mermaid software-layout diagram, the VM/native split, install steps and the
  current capability boundaries. The component layout, memory notes, release
  pipeline and development-control docs were updated to match the VM release.
- No SSH protocol or key-management change from rc.1.

## Install

1. Install the main Veil APK.
2. Install the `.vm` APK.
3. Grant the one-time AVF permissions:

   ```sh
   scripts/grant-avf
   ```

4. Open Veil → Settings → Engine → **VM (Microdroid)**, then restart Veil.

VM mode requires an AVF/Microdroid-capable device. This release candidate was
validated on a Pixel 8 running GrapheneOS. Native mode only needs the main
APK and remains manually selectable; VM failure is reported, not silently
downgraded.

## Caveats

- This is a **release candidate**, not stable.
- First VM startup takes several seconds; later sessions are faster.
- The main app still holds `INTERNET` and SSH signing authority. `.net` and
  `.vault` are not part of this release.
- The `.vm` package has no `INTERNET` permission and never receives private
  keys.
- Memory use includes the app, VM host and guest; no total-memory guarantee
  is claimed yet.
- Native mode has weaker isolation than the protected VM.
